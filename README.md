# 🧭 CURATED-ESCAPES

> An immersive editorial travel platform and interactive companion mobile booking experience.

**CURATED-ESCAPES** is a front-end project that pairs editorial-style travel landing pages with a mobile hotel-booking companion UI. It explores three visual moods: dark and cinematic, bright and playful, and clean and functional.

## 📸 Screens

### 1. Beyond the Ordinary — *Off Grid / Curated Escapes*
A magazine-style hero with a bold condensed headline and a bento grid of three escapes:

- **01 / Altitude** – Dolomites, Italy · 6-day small-group mountain adventure
- **02 / Tide** – Lofoten, Norway · coastal retreat
- **03 / After Hours** – Kyoto, Japan · lantern-lit lanes and local stories

Design notes: condensed display type, monospace metadata labels, lime-green accent, full-bleed photography with gradient overlays.

![Beyond the Ordinary](assets/screenshots/beyond-the-ordinary.png)

### 2. A little more somewhere — *The Good Days Journal*
Three alternating colour-block cards, each with a destination photo and location tag:

- **Chase your mountain high.** – Madeira, Portugal
- **Do very little. Beautifully.** – Milos, Greece
- **Get lost. Find your people.** – Lisbon, Portugal

Design notes: peach, sky-blue and butter-yellow cards, purple accent, friendly rounded sans-serif.

![A little more somewhere](assets/screenshots/a-little-more-somewhere.png)

### 3. Stay Booking App — *Home · Property Detail · Schedule*
- **Home:** search bar, city chips, "Nearby you" cards and popular stays
- **Property detail:** photo gallery, rating, amenities, date picker, price and *Book a stay* CTA
- **Schedule:** calendar, upcoming and past stays, booking status badges

![Stay Booking App](assets/screenshots/stay-booking-app.png)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) 18 or newer
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/code-with-rv/CURATED-ESCAPES.git

# Move into the project
cd CURATED-ESCAPES

# Install dependencies
npm install

# Start the dev server (opens http://localhost:3000)
npm run dev
```

### Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Starts the Vite dev server on port 3000 and opens the browser |
| `npm run build` | Creates an optimized production build in `dist/` |
| `npm run preview` | Serves the production build locally for testing |
